# Project Objectives

The goal of this project is to create a simple, interactive Web User Interface for solving nonograms (picross) of any size.

## Key Features

- **Visual & Interactive**: Provide a clear visualization of the nonogram board.
- **Multiple Strategies**: Allow the user to select between different solving strategies.
- **Step-by-Step Processing**: Let the user step through the algorithm piece-by-piece to see how a strategy solves the board.
- **Pause & Resume**: Users should be able to stop between "steps" to check the current state of the board, or let it run uninterruptedly.
