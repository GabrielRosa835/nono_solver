# Strategy Specifications Summary

* **[Anchor.Composite.md](./Anchor.Composite.md)**: Defines the `Anchor.Composite` strategy, which sequentially orchestrates both `Anchor.Start` and `Anchor.End` on a board line to bound or fill hints anchored at both line boundaries in a single low-complexity pass.
* **[Anchor.End.md](./Anchor.End.md)**: Documents the implemented `Anchor.End` strategy, which scans backwards from the end of a board line (skipping established `Empty` cells) to complete a partially filled trailing block or bound a completed last hint with an `Empty` cell.
* **[Anchor.Overlap.md](./Anchor.Overlap.md)**: Details the `Anchor.Overlap` strategy, an advanced deduction rule that locates `Filled` cells near a boundary that must belong to the edge hint and fills the intersection of all valid placements covering that cell.
* **[Anchor.Start.md](./Anchor.Start.md)**: Documents the implemented `Anchor.Start` strategy, which scans from the beginning of a board line (skipping leading `Empty` cells) to extend a boundary-touching `Filled` block to the first hint's length or cap it with an `Empty` cell.
* **[Anchor.md](./Anchor.md)**: Introduces the `Anchor` family of nonogram solving strategies, which leverage board edges and established `Empty` boundary cells to deterministically associate filled blocks with the first or last hints of a line.
* **[AutoFill.CompleteLine.md](./AutoFill.CompleteLine.md)**: Documents the implemented `AutoFill.CompleteLine` generator strategy, which checks if a row or column already satisfies all of its hint sizes in order and marks every remaining `Unknown` cell in that line as `Empty`.
* **[AutoFill.md](./AutoFill.md)**: Overview of the `AutoFill` strategy family, comprising basic quality-of-life completion algorithms that mark trivial remaining cells as `Empty` or `Filled` once a line or section requires no deeper deduction.
* **[Intersection.Basic.md](./Intersection.Basic.md)**: Documents the implemented `Intersection.Basic` generator strategy, which calculates the overlap between earliest and latest possible hint packings across a full, unpartitioned board line and marks guaranteed cells `Filled`.
* **[Intersection.Perfect.md](./Intersection.Perfect.md)**: Specifies the planned `Intersection.Perfect` strategy, an exhaustive solver that enumerates all valid permutations of hints across fragmented sections and commits cells that share an identical state across 100% of permutations.
* **[Intersection.Smart.md](./Intersection.Smart.md)**: Documents the implemented `Intersection.Smart` generator strategy, which splits a line by `Empty` cells, greedily packs hints left-to-right into fitting sections, and applies overlap intersection within each section.
* **[Intersection.md](./Intersection.md)**: Overview of the `Intersection` strategy family, the foundational nonogram solving approach that identifies guaranteed `Filled` cells by intersecting the earliest and latest valid positions of each hint in a line.
* **[Maximal.Advanced.md](./Maximal.Advanced.md)**: Specifies the planned `Maximal.Advanced` strategy, which filters out already isolated and solved hints to determine the largest remaining unsolved hint size and bounds matching `Filled` blocks with `Empty` cells.
* **[Maximal.Basic.md](./Maximal.Basic.md)**: Documents the implemented `Maximal.Basic` strategy, which finds the global maximum hint value in a line and immediately bounds any contiguous `Filled` block of that exact length with `Empty` cells on both sides.
* **[Maximal.md](./Maximal.md)**: Overview of the `Maximal` strategy family, which uses global or regressive maximum hint sizes in a line to bound floating `Filled` blocks in the interior of the grid without requiring any edge anchors.
* **[Validation.InsufficientSpace.md](./Validation.InsufficientSpace.md)**: Specifies the planned `Validation.InsufficientSpace` sanity-check strategy, which verifies that the available playable space in a line is sufficient to fit all remaining unsolved hints and their mandatory separators.
* **[Validation.OversizedBlock.md](./Validation.OversizedBlock.md)**: Documents the implemented `Validation.OversizedBlock` sanity-check strategy, which scans a line for any contiguous `Filled` block whose size exceeds the largest hint in the line and returns `StrategyResult.Faulted`.
* **[Validation.UnmatchableBlock.md](./Validation.UnmatchableBlock.md)**: Specifies the planned `Validation.UnmatchableBlock` sanity-check strategy, which detects isolated playable sections containing `Filled` cells that are smaller than every remaining hint in the line, faulting the board.
* **[Validation.md](./Validation.md)**: Overview of the `Validation` strategy family, which acts as mathematical sanity checkers during solving to detect impossible board states early and halt execution with a `StrategyResult.Faulted` result.
