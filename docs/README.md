# Nonosolver Documentation

This directory contains the documentation for the Nonosolver project.

## Directory Structure

- `objectives.md`: The main goals and objectives of the project.
- `sessions/`: Contains logs and progress notes for each development session.
  - `2026-09-29_Strategy_Contract_Design`: Initial setup and Strategy Generator contract design.
  - `2026-10-02_Strategy_Implementation`: Refactoring core logic and enriching domain models for Strategies.
  - Each folder inside `sessions/` is named `YYYY-MM-DD_Session_Purpose` and details decisions and actions taken during that session.
