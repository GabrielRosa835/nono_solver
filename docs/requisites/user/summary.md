# User Requisites Summary

* **[URQ_001-interactive-nonogram-board.md](./URQ_001-interactive-nonogram-board.md)**: Requires a single-page editable nonogram board supporting variable grid sizes, visual `Unknown`/`Filled`/`Empty` cell states, a bottom `Filling` vs. `Empty` click-mode switch, and `+`/`-` hint controls on every row and column.
* **[URQ_002-strategy-selection-and-playback.md](./URQ_002-strategy-selection-and-playback.md)**: Requires interactive controls for selecting solving strategies, stepping through atomic cell changes piece-by-piece, pausing and resuming continuous solver execution, and viewing terminal `Completed`, `Stalled`, or `Faulted` states.
